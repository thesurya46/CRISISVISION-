# CRISISVISION-AI 

CRISISVISION-AI is an advanced, AI-powered crisis management and intelligence platform designed to provide real-time insights, proactive alert feeds, and predictive analytics for severe events.

## Features

- **Real-Time Alert Feed**: Stay updated with live alerts and notifications for ongoing incidents.
- **Weather Intelligence**: Integrated weather monitoring and forecasting to anticipate weather-related crises.
- **Severity Predictor**: Leverage predictive models to estimate the potential severity and impact of emerging crises.
- **AI Assistant**: A built-in AI assistant to help analyze data, answer queries, and support decision-making during critical events.
- **Interactive Dashboard**: A comprehensive, real-time dashboard for a high-level overview of active situations and intelligence feeds.

## Tech Stack
 
- **Frontend**: React, Vite, Tailwind CSS, Framer Motion, Recharts
- **Backend**: Express.js, Node.js, tRPC
- **Database & ORM**: PostgreSQL, Drizzle ORM
- **Other Tools**: Google Maps integration for geographic intelligence

## Getting Started

1. Clone the repository
2. Install dependencies with `pnpm install`
3. Configure environment variables (e.g., database connection, API keys)
4. Run the development server with `pnpm run dev`
